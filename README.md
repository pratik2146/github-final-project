# Simple Interest Calculator

## Description
A simple calculator that calculates Simple Interest based on the Principal Amount, Rate of Interest, and Time.

## Formula

Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time

## Example

If:
- Principal = ₹10,000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = ₹1,000

## Features

- Easy to use
- Calculates simple interest quickly
- Takes principal, rate, and time as inputs
